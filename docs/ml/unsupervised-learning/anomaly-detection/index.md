## 🎯 What is Anomaly Detection?

**Anomaly detection** identifies data points that significantly deviate from the normal pattern.

**Types of Anomalies:**
- **Point anomalies:** Individual unusual instances
- **Contextual anomalies:** Unusual in specific context
- **Collective anomalies:** Groups of unusual instances

**Real-World Applications:**
- 💳 Credit card fraud detection
- 🔒 Network intrusion detection
- 🏭 Manufacturing defect detection
- 🏥 Medical diagnosis
- 📊 System monitoring
