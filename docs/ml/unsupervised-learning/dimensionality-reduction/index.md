## 🎯 What is Dimensionality Reduction?

**Dimensionality reduction** transforms high-dimensional data to lower dimensions while retaining important information.

**Why Reduce Dimensions?**
- 📊 **Visualization:** Plot in 2D/3D
- ⚡ **Speed:** Faster algorithms
- 🎯 **Avoid curse of dimensionality**
- 🔍 **Remove noise**
- 💾 **Compression**
