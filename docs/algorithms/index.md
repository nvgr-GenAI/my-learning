=== "Time Complexity"
    | Complexity | Name | Example | When to Use |
    |------------|------|---------|-------------|
    | O(1) | Constant | Array access, hash lookup | Direct access operations |
    | O(log n) | Logarithmic | Binary search, BST | Divide & conquer on sorted data |
    | O(n) | Linear | Array traversal | Single pass through data |
    | O(n log n) | Linearithmic | Merge/heap sort | Efficient sorting |
    | O(n²) | Quadratic | Nested loops | Small datasets |
    | O(2ⁿ) | Exponential | Subsets, backtracking | Brute force (small inputs) |

    **Weekly Review:** Revisit problems from 1 week ago • Identify weak patterns • Track progress and adjust plan

=== "Problem-Solving Approach"
    **5-Step Framework:** Understand → Plan → Implement → Optimize → Review

    **Pattern Recognition Guide:**

    | Problem Type | Data Structure/Approach |
    |--------------|------------------------|
    | Multiple conditions | Hash table or set |
    | Sorted array | Binary search |
    | Need ordering | Array or linked list |
    | Unique elements only | Hash set |
    | Continuous min/max | Heap (priority queue) |
    | Tree/graph traversal | BFS (level order) or DFS |
    | Overlapping subproblems | Dynamic programming |
