# Part 7: Advanced Topics

These chapters cover the mathematics that appears in cutting-edge ML research: geometric deep learning (differential geometry), kernel methods (functional analysis), topological data analysis (topology), symmetry in neural networks (group theory), and the rigorous foundations of probability (measure theory). These topics are not required for applying ML but are essential for *creating* new ML theory and understanding the deepest results in the field.

---

## Chapters

| Chapter | Topic | Key Results |
|---------|-------|-------------|
| 7.1 | Abstract Algebra | Groups, rings, fields, symmetry, equivariant neural networks |
| 7.2 | Topology | Metric spaces, open/closed sets, compactness, connectedness |
| 7.3 | Differential Geometry | Manifolds, tangent spaces, geodesics, Riemannian metrics |
| 7.4 | Functional Analysis | Banach/Hilbert spaces, operators, RKHS, kernel methods |
| 7.5 | Measure Theory | Lebesgue measure, integration, probability as measure |
| 7.6 | [Graph Theory](graph-theory.md) | Laplacians, spectral clustering, GNN foundations, random graphs |

## Prerequisites

- All of Parts 1–6
- Mathematical maturity — comfort with proofs and abstraction
